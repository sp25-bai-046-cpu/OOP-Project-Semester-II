# PrepPilot (OOP-Project-Semester-II)

An interactive Java application that combines **Object-Oriented Programming (OOP)** principles with **AI Integration** and a modern **JavaFX UI** to create a dynamic learning environment.

## Features

*   **AI Copilot:** Real-time AI assistance to help users learn, generate hints, and understand complex topics.
*   **Interactive Assessments:** Multiple quiz modes generated and managed dynamically:
    *   Multiple Choice Questions (MCQ)
    *   Match the Column
    *   True / False (T/F)
*   **Modern UI:** A clean, responsive user interface built entirely with JavaFX.

## Tech Stack & OOP Concepts

*   **Language:** Java
*   **UI Framework:** JavaFX
*   **Architecture:** Driven by core OOP principles:
    *   *Encapsulation* for secure data management.
    *   *Inheritance & Polymorphism* for flexible quiz module creation.
    *   *Abstraction* for clean AI service integration.

##  Getting Started

### Prerequisites
*   Java Development Kit (JDK 17 or higher)
*   JavaFX SDK
*   An API Key for your integrated AI service

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd OOP-Project-Semester-II
   ```

2. **Set up your AI API Key:**
   Configure your environment variables or application properties file with your AI credentials.

3. **Run the Application:**
   * If using **Maven**: `mvn javafx:run`
   * Or simply open the project folder in your favorite **IDE** (IntelliJ / VS Code) and hit **Run**.
